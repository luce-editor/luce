# Motywy i Palety Kolorów

Luce posiada rozbudowany silnik stylów, który pozwala dostosować kolory wszystkich elementów edytora — od tokenów składni po obramowania okien, karty, terminal oraz kolor tła okna OpenGL.

---

## Wbudowane Motywy

Edytor dostarczany jest z 4 dopracowanymi motywami:

1. **VS Code Dark Modern** *(Domyślny)*: Klasyczna, stonowana ciemnoszara paleta na wzór Visual Studio Code.
2. **Catppuccin Mocha**: Ciepła, pastelowa paleta zbalansowana pod kątem redukcji zmęczenia oczu.
3. **One Dark**: Zbalansowany ciemny motyw.
4. **Nord**: Czysty, zimny motyw stawiający na czytelność.

---

## Zmiana Motywu

Motyw można zmienić w dowolnym momencie za pomocą **Command Palette**:

1. Wciśnij `Ctrl+Shift+P`
2. Wpisz `Theme:`
3. Wybierz żądany motyw (np. `Theme: Catppuccin Mocha`) i naciśnij `Enter`.

Można również zmienić go poprzez:

- **View -> Theme -> Wybierz dowolny motyw z listy dostępnych**

Kolorystyka interfejsu, podświetlanie kodu oraz kolor czyszczenia tła okna (`glClearColor`) aktualizują się natychmiastowo.
