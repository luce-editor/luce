# Skróty klawiszowe

Luce wyposażony jest w intuicyjny zestaw skrótów klawiszowych zaprojektowanych z myślą o szybkiej i wygodnej pracy z kodem.

## Nawigacja i edycja tekstu

| Skrót | Akcja | Opis |
|---|---|---|
| `Ctrl + Lewo` / `Prawo` | Skok o słowo | Przesuń kursor o całe słowo w lewo lub w prawo |
| `Ctrl + Home` / `End` | Początek / Koniec pliku | Przeskocz bezpośrednio na sam początek lub koniec bufora |
| `Shift + Strzałki` | Rozszerz zaznaczenie | Zaznaczaj tekst znak po znaku lub linia po linii |
| `Ctrl + Shift + Lewo` / `Prawo` | Zaznacz słowo | Zaznaczaj całe słowa |
| `Ctrl + D` | Zaznacz kolejne wystąpienie | Wielokursoworowe zaznaczanie kolejnego pasującego tokenu |
| `Ctrl + Kliknięcie` | Dodaj kursor | Dodawanie kolejnych aktywnych kursorów w dowolnym miejscu |
| `Ctrl + A` | Zaznacz wszystko | Zaznacz całą zawartość aktywnego dokumentu |
| `Ctrl + /` | Przełącz komentarz | Zakomentuj lub odkomentuj zaznaczone linie (`//`) |
| `Tab` | Wcięcie / Rozwinięcie Emmet | Wstaw wcięcie lub rozwiń skrót Emmet w HTML (np. `div.container`, `ul>li*3`, `!`) |
| `Ctrl + Z` | Cofnij (Undo) | Cofnij ostatnie zmiany w tekście |
| `Ctrl + Y` / `Ctrl + Shift + Z` | Ponów (Redo) | Ponów uprzednio cofnięte zmiany |
| `Ctrl + Kółko myszy` | Zoom czcionki edytora | Płynne zwiększanie i zmniejszanie rozmiaru czcionki kodu |
| `F12` / `Ctrl + Enter` | Przejdź do definicji | Przeskocz do deklaracji symbolu w projekcie |

## Zarządzanie plikami i kartami

| Skrót | Akcja | Opis |
|---|---|---|
| `Ctrl + N` | Nowy plik | Utwórz nową pustą kartę dokumentu |
| `Ctrl + O` | Otwórz plik | Otwórz okno wyboru pliku z dysku |
| `Ctrl + S` | Zapisz plik | Zapisz bieżący bufor na dysku |
| `Ctrl + W` | Zamknij kartę | Zamknij aktywną kartę edytora |
| `Ctrl + Tab` | Następna karta | Przełącz fokus na kolejną otwartą kartę |
| `Ctrl + \` | Przełącz Split View | Podziel edytor na dwa niezależne panele obok siebie |
| `Ctrl + ,` | Ustawienia (UI) | Otwórz graficzną kartę ustawień edytora |
| `Ctrl + Shift + ,` | Otwórz plik ustawień | Otwórz plik konfiguracyjny `settings.json` bezpośrednio w edytorze |

## Narzędzia wyszukiwania i nawigacji

| Skrót | Akcja | Opis |
|---|---|---|
| `Ctrl + P` | Quick Open | Błyskawiczne otwieranie plików projektu po nazwie |
| `Ctrl + Shift + P` | Command Palette | Dostęp do wszystkich poleceń edytora z promptem `>` |
| `Ctrl + Shift + F` | Szukaj w projekcie | Wyszukiwanie tekstu we wszystkich plikach projektu (Find in Files) |
| `Ctrl + G` | Przejdź do linii | Przeskocz bezpośrednio do numeru linii |
| `Ctrl + F` | Znajdź w pliku | Pasek wyszukiwania w aktywnym pliku |
| `Ctrl + H` | Zamień w pliku | Pasek wyszukiwania i zamiany w aktywnym pliku |

## Widok i panele

| Skrót | Akcja | Opis |
|---|---|---|
| `Ctrl + Shift + M` | Podgląd Markdown na żywo | Przełącz panel renderowanego podglądu dokumentu Markdown |
| `Ctrl + \`` | Przełącz terminal | Pokaż lub ukryj wbudowany panel terminala |
| `Ctrl + Shift + T` | Nowa sesja terminala | Otwórz dodatkową kartę terminala (`cmd`, `powershell`, `bash`) |
| `Ctrl + Shift + W` | Zamknij sesję terminala | Zamknij bieżącą sesję powłoki |
| `Ctrl + M` | Przełącz minimapę | Włącz lub wyłącz podgląd kodu z prawej strony edytora |
| `Ctrl + =` / `Ctrl + -` | Powiększ / Pomniejsz | Skalowanie całego interfejsu edytora |
| `Ctrl + 0` | Resetuj powiększenie | Przywróć domyślne powiększenie interfejsu (100%) |
