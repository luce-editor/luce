# Themes & Color Palettes

Luce features a comprehensive theming engine capable of skinning all editor elements—including syntax highlight tokens, UI chrome, gutter line numbers, tab headers, terminal panes, and background clear colors.

---

## Built-in Themes

Luce ships with 4 professionally tuned built-in themes:

1. **VS Code Dark Modern** *(Default)*: Classic, subtle dark slate palette inspired by Visual Studio Code.
2. **Catppuccin Mocha**: Warm, pastel soothing palette designed for high contrast and low eye fatigue.
3. **One Dark**: Balanced, iconic dark theme.
4. **Nord**: Clean, arctic cool theme focused on readability.

---

## Switching Themes

You can switch the active theme anytime via the **Command Palette**:

1. Press `Ctrl+Shift+P`
2. Type `Theme:`
3. Select your desired theme (e.g. `Theme: Catppuccin Mocha` or `Theme: One Dark`) and press `Enter`.

You can also change the theme via the top menu bar:

- **View -> Theme -> Choose any theme from the list of available themes**

The interface colors, syntax highlighting, and OpenGL background clear color (`glClearColor`) update immediately in real-time.
