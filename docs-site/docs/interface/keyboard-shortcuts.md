# Keyboard Shortcuts

Luce features keyboard shortcuts designed for fast, seamless code navigation and editing.

## Navigation & Editing

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl + Left` / `Right` | Move word by word | Jump across whole words |
| `Ctrl + Home` / `End` | Start / End of document | Jump directly to top or bottom of buffer |
| `Shift + Arrow Keys` | Extend selection | Select text character by character or line by line |
| `Ctrl + Shift + Left` / `Right` | Select word | Extend selection word by word |
| `Ctrl + D` | Select Next Occurrence | Multi-cursor selection of the next matching token |
| `Ctrl + Click` | Add Cursor | Place multiple active cursors anywhere in document |
| `Ctrl + A` | Select All | Select all text in the active document |
| `Ctrl + /` | Toggle Comment | Comment or uncomment selected lines (`//`) |
| `Tab` | Indent / Emmet Expand | Indent line or expand HTML Emmet abbreviation (e.g. `div.container`, `ul>li*3`, `!`) |
| `Ctrl + Z` | Undo | Revert recent edits |
| `Ctrl + Y` / `Ctrl + Shift + Z` | Redo | Re-apply reverted edits |
| `F12` / `Ctrl + Enter` | Go to Definition | Jump to symbol declaration across project workspace |

## File & Tab Management

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl + N` | New File | Create a new unnamed document tab |
| `Ctrl + O` | Open File | Open system file picker to select and load a file |
| `Ctrl + S` | Save File | Write buffer changes to disk |
| `Ctrl + W` | Close Tab | Close the active editor tab |
| `Ctrl + Tab` | Next Tab | Switch focus to the next open tab |
| `Ctrl + \` | Toggle Split View | Split editor into two side-by-side editing panes |

## Search & Navigation Tools

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl + P` | Quick Open | Search and open files in workspace by filename |
| `Ctrl + Shift + P` | Command Palette | Access all editor commands and actions with prompt `>` |
| `Ctrl + Shift + F` | Find in Files | Project-wide text search across all workspace files |
| `Ctrl + G` | Go to Line | Jump directly to a specific line number |
| `Ctrl + F` | Find | In-editor text search overlay |
| `Ctrl + H` | Replace | In-editor search and replace overlay |

## View & Panels

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl + Shift + M` | Live Markdown Preview | Toggle live rendered Markdown preview panel |
| `Ctrl + \`` | Toggle Terminal | Show or hide embedded terminal panel |
| `Ctrl + Shift + T` | New Terminal Session | Open an additional terminal tab (`cmd`, `powershell`, `bash`) |
| `Ctrl + Shift + W` | Close Terminal Session | Terminate and close current terminal tab |
| `Ctrl + M` | Toggle Minimap | Toggle code thumbnail overview on the right |
| `Ctrl + =` / `Ctrl + -` | Zoom In / Zoom Out | Adjust entire IDE user interface scaling |
| `Ctrl + 0` | Reset Zoom | Reset interface scaling to default 100% |
