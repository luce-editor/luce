# UPPERCASE Converter

Instantly converts the currently highlighted text selection to uppercase letters.

## Features

- **In-place Replacement**: Transforms selection preserving multi-line blocks and indentation.
- **Status Reporting**: Informs the user of total character count converted.
- **Cursor Stability**: Keeps editor focus right after replacement.

## Commands

- `Ctrl+Shift+P` → **"UPPERCASE: Convert Selection"**
