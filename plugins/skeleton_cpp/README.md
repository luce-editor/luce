# Skeleton

Quickly scaffolds clean C++ boilerplate files and header definitions with a single shortcut or command.

## Features

- **Main Program Skeleton**: Inserts a standard `#include <iostream>` and `int main()` block.
- **Header Class Boilerplate**: Automatically infers class name from current filename and generates an `#pragma once` header class definition with constructor and destructor.
- **Editor Notifications**: Provides instant feedback via Luce notifications.

## Commands

- `Ctrl+Shift+P` → **"Skeleton: Insert Basic Skeleton"**
- `Ctrl+Shift+P` → **"Skeleton: Insert Header Skeleton"**
