# JSON IntelliSense & Schema Plugin for Luce

Provides autocompletion and schema suggestions for `.json` files, with full IntelliSense support for Luce's `settings.json`.

## Features
- **JSON Primitives**: `true`, `false`, `null`
- **Settings.json Schema**:
  - Root: `"$schema"`, `"editor"`, `"ui"`
  - Editor settings: `"font_size"`, `"tab_size"`, `"use_spaces"`, `"show_minimap"`, `"show_line_numbers"`, `"highlight_current_line"`, `"zoom_with_mouse_wheel"`, `"cursor_blinking"`
  - UI settings: `"font_size"`, `"scale"`, `"theme"`, `"auto_save"`
  - Themes: `"VS Code Dark 2026"`, `"Catppuccin Mocha"`, `"One Dark"`, `"Nord"`, `"Dracula"`
