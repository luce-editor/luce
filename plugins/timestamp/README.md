# Timestamp Inserter

Inserts standard ISO 8601 UTC date and time into code files with comments.

## Features

- **ISO 8601 UTC Formats**: Generates standardized timestamps (e.g. `// 2026-09-12T15:30:00Z`).
- **Date-Only Quick Insert**: Injects current calendar date directly at cursor.
- **Status Bar Confirmation**: Echoes the formatted string to the editor status bar.

## Commands

- `Ctrl+Shift+P` → **"Timestamp: Insert Date & Time"**
- `Ctrl+Shift+P` → **"Timestamp: Insert Date Only"**
