# C++ Snippets & Helpers

A smart completion and helper extension for **C++** in Luce.

## Features

- **Standard Library Snippets**: Quick auto-completion for common C++ types and containers:
  - `std::cout`, `std::vector`, `std::string`
  - `std::unique_ptr`, `std::shared_ptr`, `std::make_unique`, `std::make_shared`
  - `std::optional`, `std::format`, `std::views`, `std::ranges`
- **Modern C++ Keywords**:
  - `constexpr`, `consteval`, `noexcept`, `override`, `nodiscard`
- **Fast Fuzzy Matching**: Non-blocking auto-complete popup as you type in `.cpp`, `.cxx`, `.cc`, and `.h` files.

## Usage

Simply start typing any prefix (e.g. `vec`, `uniq`, `opt`) in a C++ file, and select the completion with `Tab` or `Enter`.
